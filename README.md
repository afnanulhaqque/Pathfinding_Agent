# Pathfinding Agent

A Python project for exploring pathfinding algorithms and visualizing their
results in a maze.

## Project structure

| File or folder | Responsibility |
| --- | --- |
| `main.py` | Main program and execution |
| `algorithms/` | BFS, Dijkstra, A*, and other algorithms |
| `visualization/` | Maze and path visualizations |
| `results/` | Performance metrics and exported logs |

## Run

Run the current example from the project root:

```bash
python main.py
```

It prints a sample grid with `S` for the start, `G` for the goal, `#` for
obstacles, and `.` for open cells.
